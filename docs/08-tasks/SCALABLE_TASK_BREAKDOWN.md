## 0. 设计约束与优先级规则

| 约束 | 来源 |
|------|------|
| 维持模块化单体（ADR-046），不拆微服务 | ADR-046, ADR-065 |
| 所有可观测性（ADR-064）先行，后续工作依赖 trace/metrics | ADR-064 |
| 图谱分片（Fabric/多集群）推迟到 Phase 5+ | ADR-062 |
| Skill 保持 in-process，仅做插件化打包 | ADR-061 |
| 租户隔离每实例独立部署（专用），不为逻辑多租户过早投资 | ADR-063 |

## 6. 风险登记表

| 风险 | 触发条件 | 应对 |
|------|----------|------|
| OTel 埋点改造成本超预期 | WR-064 工作量 > 120% | 缩范围：仅覆盖 HTTP + Graphiti + OPA，暂不埋 Skill 级别 |
| 读副本复制延迟无法控制在 5s 内 | 压测发现延迟超阈值 | 调整 SLA → 10s；写后强一致路径改走主库 |
| 冷热分层方案不成熟 | DuckDB 查询性能不达预期 | 退回到单纯归档（Neo4j 数据 + 对象存储备份），延迟冷存查询 |
| 租户数爆炸，专用部署运维撑不住 | 租户 > 10 | 启动逻辑多租户（B）方案评估，TenantIsolator 已就位改造面可控 |
| 团队人力不足 | 关键任务阻塞 | Q2 可选任务推迟，Q3 可选任务删减 |
