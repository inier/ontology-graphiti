## 1. 设计原则与概述

### 1.1 核心设计理念

本系统以**智能问答驱动本体构建**为核心场景，用户通过自然语言提问，系统自动进行意图分析、联网搜索、数据摄入，最终生成结构化本体。界面设计强调**过程可视化**与**实时反馈**，让用户直观感受从问题到本体的转化旅程。

### 1.2 设计目标

| 目标 | 描述 |
|------|------|
| **过程透明** | 将黑盒的AI处理过程白盒化，展示每个处理阶段 |
| **实时感知** | WebSocket实时推送，用户随时了解构建进度 |
| **结构清晰** | 三栏式布局，原始数据、转化过程、本体结果一目了然 |
| **交互直观** | 图谱可视化、节点可点击、关系可高亮 |

### 1.3 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19 | UI框架 |
| TypeScript | 5.x | 类型安全 |
| Ant Design | 6.x | 组件库 |
| D3.js | 7.x | 图谱可视化 |
| ECharts | 5.x | 图表 |
| React Router | 7.x | 路由 |

### 5.2 图谱交互规范

#### 节点交互

| 交互 | 行为 |
|------|------|
| 单击节点 | 选中节点，高亮显示，右侧面板展示详情 |
| 双击节点 | 展开/收起该节点的直接关系 |
| 拖拽节点 | 自由调整节点位置 |
| 悬停节点 | 显示节点名称tooltip，鼠标指针变为pointer |
| 右键节点 | 弹出上下文菜单（编辑、删除、查看关系） |

#### 关系线交互

| 交互 | 行为 |
|------|------|
| 单击关系线 | 高亮该关系及其关联的两个节点 |
| 悬停关系线 | 显示关系名称tooltip |
| 高亮状态 | 关系线加粗(3px)，颜色加深，箭头高亮 |

## 9. 技术实现建议

### 9.1 图谱可视化

推荐使用D3.js力导向图，结合以下库：

| 库 | 用途 |
|------|------|
| d3-force | 力导向布局算法 |
| d3-selection | DOM操作 |
| d3-zoom | 缩放、平移交互 |
| d3-drag | 节点拖拽 |

```
┌─────────────────────────────────────────────────────────────────┐
│                    WebSocket通信架构                             │

│         │                    │                                  │
```
