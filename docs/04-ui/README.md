## 设计系统概述

- **设计原则**: 用户友好、军事级专业、高效直观、渐进式信息展示
- **布局系统**: WorkBuddy式三栏（左栏工作空间/场景/会话历史 | 中间问答区 | 右栏扩展补充区）
- **技术栈**: React + Ant Design 6 + Zustand + Ant Design X + AntV G6 v5
