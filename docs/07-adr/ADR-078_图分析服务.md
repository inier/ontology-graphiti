# ADR-078: 图分析服务（中心性/社区/链路预测/路径）

## 状态

**Proposed**（2026-08-20，Phase 4 启动）

## 上下文

ODAP 的 Neo4j 目前仅做存储 + Cypher 查询，缺少图分析能力（中心性、社区发现、链路预测、最短路径）。这些能力是决策影响分析（ADR-076）、推演路径计算（simulation/）、多跳推理（data/qa/）的基础。

GraphManager 已有三层降级架构（Graphiti → Neo4j Driver → NetworkX 回退），图分析服务应遵循同一降级策略：Neo4j GDS（生产）/ networkx（回退），保证离线开发/测试环境可用。

## 决策

### 1. 双后端架构（与 GraphManager 降级策略一致）

```
infra/graph/analytics/
├── __init__.py
├── service.py           # GraphAnalyticsService 统一 API（门面）
├── gds_backend.py       # Neo4j GDS 后端（生产，Cypher 投影 + GDS 算法）
├── networkx_backend.py  # networkx 回退（纯内存，无外部依赖）
└── api/routes.py        # 图分析 REST API（按 workspace 隔离）
```

`service.py` 依据 `GraphManager.mode` 自动选择后端：
- `graphiti` / `neo4j_driver` → `gds_backend`
- `fallback` → `networkx_backend`
- `unavailable` → 返回错误（不降级，与 GraphManager 一致）

### 2. 统一分析 API（四类能力）

| 方法 | 能力 | 说明 |
|---|---|---|
| `centrality(graph, metric)` | 中心性 | degree / betweenness / closeness / eigenvector / pagerank |
| `community(graph, algo)` | 社区发现 | louvain / label_propagation / girvan_newman |
| `link_prediction(graph, pair)` | 链路预测 | 共同邻居 / Jaccard / Adamic-Adar / 优先连接 |
| `shortest_path(graph, src, dst)` | 最短路径 | Dijkstra / 无权 BFS |

所有方法签名统一，返回结构化 dict，消费方（simulation/、qa/）无需感知后端差异。

### 3. 图投影与 workspace 隔离

- GDS 后端：Cypher 投影（`gds.graph.project`），按 `workspace_id` 属性过滤节点/关系，保证工作空间隔离。
- networkx 后端：从 GraphManager.fallback_graph 拷贝子图（过滤 workspace_id）。
- 分析结果仅含该 workspace 的节点/边，跨 workspace 泄漏零容忍。

### 4. 技术选型

| 能力 | 选型 | 理由 |
|---|---|---|
| 图分析算法 | Neo4j GDS 库（生产）+ networkx（回退） | GDS 为 Neo4j 官方图算法库；networkx 零依赖纯 Python |
| 算法一致性 | 两端独立实现，签名对齐 | GDS 与 networkx 算法结果语义一致（中心性/社区/路径） |

networkx 已在 GraphManager 回退路径使用，无需新增依赖；GDS 依赖 Neo4j 服务器插件（生产环境）。

### 5. 与现有能力边界

- **与 ADR-075 推理引擎正交**：图分析是**结构指标**（中心性/社区），Datalog 是**规则演绎**（业务推理），不重叠。
- **与 ADR-073 检索总线协同**：图分析结果可作为检索总线的重排序特征（中心性加权）。
- **消费方**：simulation/ 推演路径、data/qa/ 多跳推理、决策影响分析（ADR-076）。

## 后果

### 正面
- 补齐图分析能力，赋能决策影响分析、推演、多跳推理
- 双后端保证离线开发/测试可跑（networkx 回退）
- workspace 隔离继承 GraphManager 语义

### 负面与缓解
- GDS 依赖 Neo4j 插件（生产环境需安装）→ 缓解：networkx 回退覆盖开发/测试，GDS 仅生产增强
- 两端算法结果可能存在细微差异 → 缓解：签名对齐 + 结果语义一致，单测覆盖两端

## 可逆性

**高**。图分析服务为旁路只读能力，不改变写入路径，移除不影响现有功能。
