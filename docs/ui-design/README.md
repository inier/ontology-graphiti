# UI设计文档索引

**本体构建系统UI设计稿** - 核心设计文档

包含内容：

- 色彩方案（主色调、阶段状态色）
- 本体构建进度展示页面布局（三栏式布局）
- 进度展示组件、阶段状态标签组件规范
- 原始数据展示组件、转化过程展示组件、本体定义展示组件
- 版本管理组件
- 本体语义网络页面设计
- 图谱交互规范与节点/关系样式
- 交互流程图
- 响应式设计规范

### 2. COMPONENT_SPEC.md
**组件规范详细说明** - 技术实现参考文档

- D3.js力导向图配置参数
- CSS样式规范
- 响应式断点
