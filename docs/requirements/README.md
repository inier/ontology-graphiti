## 使用指南

### 开发时只看 req-ok.md

所有开发工作应基于 `req-ok.md`，这是唯一权威需求来源。

### 查阅历史需求

如需了解需求演进历史，可查看 `archive/` 目录下的文档。

### 更新需求流程

1. 在 `req-ok.md` 中更新需求
2. 更新版本号和变更记录
3. 同步更新相关架构文档
