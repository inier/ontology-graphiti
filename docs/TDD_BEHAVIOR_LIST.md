## 执行策略

1. **垂直切片**：按行为编号顺序执行，每次只做一个行为
2. **RED→GREEN 循环**：先写测试确认失败，再写最小实现代码确认通过
3. **功能问题穿插修复**：在执行过程中遇到 F-* 问题，立即记录并安排修复
4. **每5个行为做一次重构**：消除重复、深化模块
