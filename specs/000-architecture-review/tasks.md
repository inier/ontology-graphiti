### R-P1-005: Cryptographic downgrade safeguards ✅ DONE

**Status**: ✅ Completed 2026-06-05

**Files**:
- `odap/infra/security/auth_service.py:153-179` — bcrypt unavailable → SHA256
- `odap/infra/security/encryption.py:11-39` — cryptography unavailable → base64

**Problem**: Both files silently downgraded to insecure alternatives when
the required crypto library was missing:
- `auth_service.py` fell back to unsalted SHA-256 (fast hash, no protection)
- `encryption.py` fell back to plain base64 (no confidentiality at all)

**Fix applied**:
1. `auth_service.py` — added `assert_bcrypt_available()` at module level.
   `_hash_password` and `_verify_password` now call this first; on missing
   bcrypt, they raise `RuntimeError("SECURITY: bcrypt is not installed...")`
   instead of returning an insecure hash. The legacy `if BCRYPT_AVAILABLE`
   guards in both methods were removed.
2. `encryption.py` — added `assert_cryptography_available()` at module level.
   `encrypt_field` and `decrypt_field` now call this first; on missing
   cryptography, they raise `RuntimeError("SECURITY: cryptography is not installed...")`
   instead of returning base64-encoded plaintext. The legacy `try/except
   ImportError` returning a `{"fallback": True}` dict was removed.
3. `requirements.txt` (or `pyproject.toml`) should mark `bcrypt` and
   `cryptography` as required (not optional) — verified they are installed
   in this environment.

**Regression test added**: [test_crypto_fail_closed.py](file:///e:/DEMO/AI/ontology-graphiti/tests/unit/test_crypto_fail_closed.py) — **8 tests**
- `TestBcryptFailClose` (2 tests) — `assert_bcrypt_available()` raises when missing; happy path
- `TestCryptographyFailClose` (2 tests) — `assert_cryptography_available()` raises when missing; happy path
- `TestEncryptionRoundtrip` (1 test) — `encrypt_field` produces real AES-GCM output, no fallback marker
- `TestAuthServiceHashFormat` (1 test) — `_hash_password` uses `$2` prefix; `_verify_password` roundtrip
- `TestStaticSourceGuards` (2 tests) — AST scan prevents reintroduction of silent SHA-256 / base64 fallback

**Acceptance**:
- [x] `auth_service._hash_password` raises `RuntimeError` if bcrypt is missing
