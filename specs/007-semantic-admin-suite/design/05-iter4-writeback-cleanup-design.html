② L3~L6 四层流水线补全设计

层名称算法核心输入→输出复杂度可选跳过？
L3分类层（Taxonomy）FCA 形式概念分析：属性×对象二部图构造概念格 → 合并 LLM few-shot 层级推断 → 后处理去环L2 Candidates × 属性关系 → 候选父子对 (parent, child, confidence)O(C²·A) 中等（≤ 200 候选）可选（不跳）
L4关系层LLM 关系三元组抽取 + SchemaFusion 归并："A-V-B" 主谓宾抽取 → 按 domain/range 语义类型过滤 (人物-势力→归属OK，人物-价格→归属NO) → 归并到已有关系类型 或 新建L3 分类树 × 文档 raw_tokens → RelationType candidates[]O(C·T) 较高可选（默认）
L5模式层（SchemaFusion）Embedding 相似度 + 结构等价 + 规则一致性 三层判同："订单状态" vs "订单_状态" vs "状态(订单)" → 合并同义 Schema 元素L3+L4 合并集合 → 去重后 Schema + 等价组映射O(E²) 低不跳
L6公理层AxiomInductor 规则发现：Association Rule Mining (Apriori min_support=0.1) → 产生 ∀x,y (R(x,y) → S(x,y)) 等公理 → 结合 USL 约束验证L3 分类 × L4 关系 × 文档证据 → Axiom candidates[]O(E³) 最高（≤ 200 元素）默认跳过（配置开关）

class OLPipelineConfig(BaseModel):
    domain_id: str | None = None
    workspace_id: str
    enabled_layers: set[str] = {"L1","L2","L3","L4","L5"}  # 默认跳过 L6 公理

    fca_min_extent: int = 2                                 # L3 FCA 最小外延
    relation_confidence_cut: float = 0.65                   # L4 关系置信度截断
    fusion_embedding_sim_cut: float = 0.90                  # L5 SchemaFusion 合并阈值
    axiom_min_support: float = 0.10                         # L6 Apriori 支持度阈值
    # 写回策略
    writeback_target_usl: bool = True                       # 写 USL
    writeback_target_ontology_tbox: bool = True             # 写 Ontology TBox
    writeback_target_neo4j: bool = True                     # Neo4j 正式 TBox 命名空间（非 _schema_graph）
