## 二、已实现功能 ✅

### 总体布局架构

- [x] **4列布局**：菜单（fixed Sider）+ 右操作区（Header + 3列body）
- [x] **菜单区**：默认折叠（48px图标），点击底部按钮展开（200px）
- [x] **全局 Header**：工作空间下拉、场景下拉、国际化切换、主题切换、账号信息
- [x] **三列容器**：功能区 + 工作区 + 扩展区，`flex` 布局

### 功能区（第1列）

- [x] 默认展开状态（`taskPanelCollapsed: false`）
- [x] 折叠/展开（分隔线双击或折叠按钮）
- [x] 宽度可拖拽调整（拖分隔线）
- [x] 最小宽 5%，最大宽 30%（`clamp`）
- [x] 任务区 + 快捷操作区上下分割，高度可拖拽调整

### 任务区（功能区上部）

- [x] 列表视图 / 卡片视图切换
- [x] 列表视图：图标 + 标题 + 关闭按钮
- [x] 卡片视图：图标 + 标题 + summary + 时间 + 状态徽章
- [x] 点击 tab → 导航到对应路由
- [x] 右键菜单：刷新、关闭、关闭上方任务、关闭下方任务、关闭全部任务、添加到快捷区
- [x] 拖拽排序（tab 之间互换位置）
- [x] 拖拽到快捷区（`dataTransfer.setData / getData`）
- [x] 路由变化自动新增 tab（`openTab` in ProLayout）
- [x] **Keep-alive**：`KeepAliveOutlet` 基于 React 19 `<Activity>`，tab 切换时保留组件状态

### 快捷操作区（功能区下部）

- [x] 显示快捷图标（已固定的路由快捷方式）
- [x] 点击快捷图标 → 导航
- [x] 拖拽 tab 到此区域 → 自动添加快捷操作
- [x] 右键/关闭按钮移除快捷操作
- [x] 高度可拖拽调整（最小5%，最大40%）

### 工作区（第2列）

- [x] `flex: 1` 自适应宽度
- [x] 全局 Loading 层
- [x] AI助手悬浮按钮（点击打开/关闭扩展区）
- [x] 路由内容在此渲染（`{children}`）

### 扩展区（第3列）

- [x] 默认折叠（`extensionPanelCollapsed: true`）
- [x] 折叠/展开（悬浮按钮或分隔线）
- [x] 宽度可拖拽调整
- [x] `ExtensionPanel` 基础外壳（标题栏 + 关闭按钮 + content区）

### 状态持久化

- [x] Zustand `persist`：折叠状态、宽度比例、视图模式、tabs 列表、快捷操作全部持久化到 `localStorage`

## 三、缺失或待完善功能 ❌ / ⚠️

### 3.1 菜单区 — 中优先级

| 需求 | 状态 | 说明 |
|------|------|------|
| Header 中放置"我的智能体"入口 | ⚠️ 部分实现 | 目前是"我的智能体/管理后台"切换按钮，但未在 Header 明确标注为"我的智能体"入口，视觉层级不突出 |
| 主题颜色选择器（多套配色切换） | ❌ 缺失 | 当前仅支持 light/dark 两种模式切换（emoji 按钮），无颜色主题选择器（无 Indigo/Blue/Green 等颜色切换） |
| Header 账号信息展开菜单完善 | ⚠️ 待完善 | 账号菜单仅有"退出登录"，缺少"个人设置"、"账号信息"等选项 |

### 3.2 功能区 — 高优先级

| 需求 | 状态 | 说明 |
|------|------|------|
| 任务区"删除" tab 菜单项 | ❌ 缺失 | 右键菜单中有"关闭"但没有明确的"删除"选项（语义上"关闭"≈"删除"，但需求明确要求有"删除"） |
| 卡片视图展示概要信息 | ⚠️ 占位 | `tab.summary` 字段存在但没有自动填充机制；路由跳转时仅记录 `title`，未抓取页面摘要 |
| 点击任务 tab 在**第3列**显示详情 | ❌ 缺失 | 需求：点击 tab 可在扩展区（第3列）显示详情；当前点击 tab 是直接导航到对应路由，没有"在扩展区查看详情"的功能 |
| 功能区折叠时有"迷你栏"提示 | ⚠️ 简陋 | 折叠时只有一个 24px 宽的箭头按钮，无图标预览、无 Tab 数量徽章 |

### 3.3 工作区 — 低优先级

| 需求 | 状态 | 说明 |
|------|------|------|
| 工作区顶部 Tab Bar（浏览器式标签页） | ❌ 缺失 | 需求中描述工作区有"Tab Bar + 内容区"模式，但当前工作区只有路由内容，没有顶部标签条 |
| 工作区最小宽度限制 | ⚠️ 待加强 | 目前 `flex: 1` 会无限压缩工作区；三列同时展开时可能导致工作区过窄 |

### 3.4 扩展区 — 中优先级

| 需求 | 状态 | 说明 |
|------|------|------|
| 扩展区 AI 助手内容 | ❌ 空壳 | `ExtensionPanel` 仅有外壳，`children` 为空时显示"扩展内容区"占位文字，无真实 AI 对话功能 |
| 扩展区折叠时的迷你触发按钮 | ⚠️ 依赖浮动按钮 | 只有工作区右下角的 FloatButton 可以打开扩展区，无专属的扩展区折叠/展开切换按钮在分隔线处 |
| 扩展区支持多 Tab（AI助手/其他扩展） | ❌ 缺失 | 当前扩展区只有单一内容容器，无 Tab 切换功能 |

### 3.5 整体体验 — 中优先级

| 需求 | 状态 | 说明 |
|------|------|------|
| 拖拽宽度调节的精度 | ⚠️ 有 bug | `handleTaskPanelResize` 直接叠加 `deltaPercent` 而不是基于起始状态，长时间拖拽会产生累计误差 |
| 快捷区重置/清空操作 | ❌ 缺失 | 无"清空全部快捷操作"按钮 |
| 键盘快捷键支持 | ❌ 缺失 | 原型中设计了 `Ctrl+\`（折叠菜单）、`Ctrl+]`（展开扩展区）等快捷键，实际未实现 |
| 响应式/小屏适配 | ❌ 缺失 | `minWidth: 1200` 硬限制，小屏幕无降级方案 |

## 四、技术债务

| 项目 | 位置 | 说明 |
|------|------|------|
| `AppLayout.tsx` 仍存在 | `shared/components/` | 老版 AppLayout（含完整菜单逻辑）仍存在，与 ProLayout 逻辑重复，需要清理或明确废弃 |
| `SplitPane.tsx` 与 `ResizeHandle` 重复 | `shared/components/` | ProLayout 内有内联 `ResizeHandle`，同时还有独立的 `SplitPane.tsx`，两套调整宽度实现 |
| 拖拽宽度累计误差 | `ProLayout.tsx` L470~484 | `handleTaskPanelResize` 每次拖拽都基于"当前宽度"叠加增量，应改为基于拖拽起点绝对计算 |
| `TaskTab.id` 与路由 path 混用 | `layoutStore.ts` | `openTab` 内 `existing` 用 `t.path` 做查找但 `id` 可以独立设置，有潜在重复 key 风险 |

## 五、优先级总结

### P0 — 核心功能完善（1-2天）

1. **主题颜色选择器**：在 Header 添加颜色主题选择（非仅亮/暗模式）
2. **点击 tab 在第3列显示详情**：扩展区作为 Tab 详情预览面板
3. **拖拽宽度 bug 修复**：累计误差问题

### P1 — 功能补全（2-3天）

4. **工作区 Tab Bar**：工作区顶部增加浏览器式标签条（可选）
5. **扩展区 AI 助手内容接入**：接入现有 `AIAssistantPanel` 组件
6. **功能区折叠迷你栏优化**：折叠状态显示 tab 数量徽章、图标列表
7. **账号菜单完善**：加入个人设置等选项
8. **"删除"右键菜单项**：与"关闭"语义区分

### P2 — 体验优化（3-5天）

9. **键盘快捷键**：`Ctrl+\`、`Ctrl+]` 等
10. **Tab 摘要自动填充**：卡片视图的 summary 字段自动抓取
11. **扩展区多 Tab**：AI助手 + 其他扩展面板
12. **清理废弃代码**：AppLayout.tsx 归档、SplitPane 统一
